FINAL AUDIT LIMITATIONS / NOTES
===============================
1. This is a local multi-node Kind/WSL lab, not a managed production cluster.
2. WSL/Docker DNS can become stale after WSL shutdown/restart. During audit,
   Kind node DNS required repair before GHCR image pulls could continue.
3. fs.inotify.max_user_instances required adjustment for kube-proxy after
   WSL restarts.
4. Jenkins authorization uses FullControlOnceLoggedIn and should be replaced
   with enterprise RBAC/SSO for real multi-user deployment.
5. API image digests changed across separate builds of the same source commit
   because some base/system/Python dependency inputs are dynamically resolved.
   Immutable promotion within each pipeline run is verified, but fully
   reproducible builds would require stronger dependency/base-image pinning.
6. BuildKit has scoped rootless security-profile exceptions required by this
   local environment.
7. Gitleaks was not installed during this audit; no claim of a Gitleaks scan
   is made.
8. Kind-specific Kubernetes API networking values must be replaced with the
   appropriate private/control-plane networking design in EKS or another
   managed Kubernetes platform.
